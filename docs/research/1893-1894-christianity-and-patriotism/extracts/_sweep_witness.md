# Witness Sweep — «Христианство и патриотизм» (Christianity and Patriotism)

Composition window: 8 Oct 1893 – 17 Mar 1894 (draft sent to translators Apr 1894)
Sweep date: 2026-06-07
Sources: PSS T52 (diary), T66, T67, T84, T87 (letters)

## Notes on file mapping

The TEI letter filename numbers are **letter-sequence numbers**, not PSS page numbers. The brief's
"T87 p.232 / p.234 / p.236" refers to PSS page ranges covered by v87_351, v87_352, v87_353
respectively — all three are present in the corpus.

Two diary entries are in TEI files whose **filename date differs from the PSS-printed date**:

- D1 ("3 Nov 1893"): the entry is printed across pp.103–104; the TEI file is `v52_103_104_1893_10_06`
  (filename date = 6 Oct 1893), but the file's text explicitly opens "Нынче 3 Ноября 1893."
- D5 ("23 Mar 1894"): the entry is printed across pp.112–114; the TEI file is `v52_112_114_1894_03_09`
  (filename date = 9 Mar 1894), but the text opens "⁹¹ Февраля 94. Я. П. Е. б. ж. 23 Марта. Москва."

The stub files `v52_104_104_1893_11_04` and `v52_114_114_1894_03_24` contain only an opener line
("Е. б. ж.") with no body text; the substantive entries are in the two files above.
