## Work-orders (not openly digitised — request access)

1. **«Круг чтения», изд. Посредник, Москва, 1906** — title page / cover of the first Posrednik edition.
   - Where to look: РГБ (Российская государственная библиотека) digital catalogue `search.rsl.ru`; НЭБ `rusneb.ru` (search: «Круг чтения» Толстой 1906); Государственный музей Л. Н. Толстого (goslitmuz.ru/tolstoy) photo archive.
   - Archive.org search (`krug chteniya posrednik`) returned no match. Commons search also blank.
   - access: request

2. **Running the gauntlet / Спицрутены (сквозь строй) — period illustration**.
   - Relevant to the punishment scenes in «За что?» and «Божеское и человеческое».
   - Commons searches for gauntlet/Spiesruten/skvoz stroj all returned no usable file-namespace hits.
   - Where to look: BnF Gallica (gallica.bnf.fr — search "supplice des baguettes" or "bastonnade militaire"); Russian State Historical Museum (shm.ru) print collection; Europeana.
   - access: request

3. **Wincenty Migurski / Albina Migurski portrait** — the real couple behind «За что?».
   - No image found on Commons or via Wikipedia article-image probe.
   - Where to look: Biblioteka Narodowa (bn.org.pl); Muzeum Historii Polski; Polish State Archives (archiwa.gov.pl).
   - access: request

4. **«Сибирь и каторга» (Максимов) title page / frontispiece** — the source book for «За что?».
   - Not found on Commons. Archive.org has no clean hit for the 1871 St. Petersburg edition.
   - Where to look: archive.org (search identifier patterns for 1871 Russian imprints); НЭБ; hathitrust.org.
   - access: request

5. **Gorbunov-Posadov arrest / trial 1911 — press photograph or court document**.
   - No image found. Would document the censorship consequence of Krug Chteniya publication.
   - Where to look: ГАРФ (State Archive of the Russian Federation) — trial records; Russian newspaper digitisations at НЭБ (Новое время, Русские ведомости 1911).
   - access: request
